- **混合搜索主入口**：`src/core/search/hybrid.ts` 导出 `hybridSearch()` 和 `hybridSearchCached()`，后者通过 `knobs_hash` 防止跨模式/跨引擎缓存污染。
- **搜索模式解析**：`src/core/search/mode.ts` 定义 `MODE_BUNDLES`（conservative/balanced/tokenmax），解析链为：`per-call SearchOpts → per-key config → MODE_BUNDLES[mode] → balanced (fallback)`。
- **查询扩展**：`src/core/search/expansion.ts` 实现 LLM 多查询扩展，仅 tokenmax 模式启用。
- **去重**：`src/core/search/dedup.ts` 源感知去重，保证 compiled truth 不被覆盖。
- **意图分类**：`src/core/search/intent.ts` 分类为 entity/temporal/event/general。
- **源加权**：`src/core/search/source-boost.ts` 实现 SQL CASE 构建，最长前缀匹配。
- **关系召回**：`src/core/search/relational-recall.ts` + `relational-intent.ts` 实现知识图谱边遍历，仅在 balanced/tokenmax 中启用。
