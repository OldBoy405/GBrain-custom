- **开发运行**：`bun run src/cli.ts <command>` 直接执行 CLI 命令（无需编译）。
- **编译二进制**：`bun build --compile --outfile bin/gbrain src/cli.ts`。
- **MCP 服务器**：`gbrain serve` 启动 stdio MCP 服务；`gbrain serve --http` 启动 HTTP 传输。
- **引擎选择**：通过 `gbrain init` 交互式选择 PGLite 或 Postgres；通过 `config.json` 中的 `engine` 字段切换。
- **类型检查**：`bun run typecheck`（等价于 `tsc --noEmit`）。
