- **启动 stdio MCP**：`gbrain serve` — 通过 stdin/stdout 与 AI 代理通信。
- **启动 HTTP 服务**：`gbrain serve --http` — 启用 REST API + OAuth。
- **直接调用操作**：`gbrain call <op-name> '<json-params>'` — 设置 `remote=false`，绕过 MCP 信任限制。
- **关键测试**：`test/e2e/http-transport.test.ts`（Bearer 认证、速率限制）、`test/e2e/serve-http-oauth.test.ts`（OAuth 2.1 全流程）。
