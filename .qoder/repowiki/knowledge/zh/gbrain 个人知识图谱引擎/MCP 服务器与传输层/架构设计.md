- **双传输共享调度**：`src/mcp/dispatch.ts` 是 stdio 与 HTTP 传输的单一事实来源。两种传输验证相同的参数、构建相同的 `OperationContext`、并以相同方式序列化错误。
- **stdio 传输**：`src/mcp/server.ts` 使用 `@modelcontextprotocol/sdk` 的 `StdioServerTransport`。所有 stdio 调用者默认为 `remote=true`（不可信），takes 持有者白名单为 `['world']`。
- **HTTP 传输**：`src/commands/serve-http.ts` 实现 Express 服务器，支持 Bearer Token 认证、OAuth 2.1、CORS 白名单、请求体大小限制、双桶速率限制。
- **工具定义生成**：`src/mcp/tool-defs.ts` 的 `buildToolDefs()` 从 operations 数组生成 MCP 工具 schema，子代理工具注册表复用同一映射器。
- **检索反射 IPC**：PGLite 模式下，serve 进程通过 Unix socket 提供实体解析服务（`resolve-ipc.ts`），避免打开第二个数据库连接。
- **元数据注入**：`metaHook` 机制在工具调用成功后注入 `_meta.brain_hot_memory`，让 Claude Desktop/Code 自动看到大脑的热记忆。尽力而为，失败不阻断。
