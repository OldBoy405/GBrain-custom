- **信任边界**：`OperationContext.remote` 是核心安全字段。`src/cli.ts` 设置 `remote=false`（可信本地），`src/mcp/server.ts` 和 HTTP 传输设置 `remote=true`（不可信远程）。信任是 fail-closed：任何非显式 `false` 的值都被视为远程/不可信。
- **源隔离封印**：所有读取操作通过 `sourceScopeOpts(ctx)` 路由，优先级为：联合数组（`ctx.auth.allowedSources`）> 标量（`ctx.sourceId`）> 无。源 ID 唯一性约束为 `(source_id, slug)`。
- **OAuth 2.1**：支持 `client_credentials`（机器对机器）和 `authorization_code` + PKCE（用户交互）两种授权流程。实现包含客户端注册（DCR）、令牌轮换、撤销、过期清扫。
- **Takes 持有者白名单**：per-token 的 `takesHoldersAllowList` 控制远程调用者能看到哪些 take holder，本地调用者无此限制。
- **速率限制**：HTTP 传输实现双桶速率限制（IP 级别 + 令牌级别），LRU 驱逐、TTL 清理。
- **文件系统安全**：`file_upload` 操作在 `remote=true` 时收紧文件系统限制范围，默认 cwd 目录，禁止符号链接遍历。
