- **队列核心**：`src/core/minions/queue.ts` (~1500 行) 实现作业 CRUD、状态机（pending→running→done/failed）、依赖图、完成/失败回调。
- **监督器**：`src/core/minions/supervisor.ts` (~1150 行) 管理 worker 生命周期、锁续约心跳、停滞检测（连续 N 次无心跳→标记 stalled）、级联终止。
- **Worker**：`src/core/minions/worker.ts` (~1100 行) 执行具体作业。Shell worker 通过子进程运行命令；Subagent worker 调用 LLM 执行结构化任务。
- **Handler 系统**：`src/core/minions/handlers/` 包含专用处理器：`embed-backfill`（嵌入回填）、`shell`（通用 Shell 作业）、`subagent`（LLM 子代理）、`contextual-reindex-per-chunk`（上下文重索引）。
- **Protected Names**：`protected-names.ts` 定义受保护的任务名（shell、synthesize、patterns、consolidate 等），远程 MCP 调用者禁止提交这些任务。
- **锁机制**：`lease-cap-controller.ts` 和 `lock-renewal-tick.ts` 管理数据库级锁（`gbrain_cycle_locks` 表），支持 TTL、窃取宽限期、续约失败检测。
- **预算追踪**：`budget-tracker.ts` 和 `budget-meter.ts` 追踪 AI API 调用成本，支持 per-job 和全局预算上限。
- **子代理工具**：`tools/brain-allowlist.ts` 定义子代理可用的脑操作白名单，防止子代理执行危险操作。
