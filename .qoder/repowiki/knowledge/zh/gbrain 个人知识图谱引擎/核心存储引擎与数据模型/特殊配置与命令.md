- **Schema 查看**：`src/schema.sql` 包含完整的 Postgres DDL；`src/core/pglite-schema.ts` 包含 PGLite 嵌入式 Schema。
- **迁移执行**：`gbrain apply-migrations --yes` 手动触发 Schema 迁移；`gbrain doctor` 检测并报告迁移状态。
- **引擎切换**：`gbrain migrate --to supabase` 支持从 PGLite 迁移到 Supabase。
- **Schema 构建**：`bun run build:schema` 执行 `scripts/build-schema.sh` 重新生成 Schema 产物。
- **关键测试**：`bun test test/migrate.test.ts` 验证迁移逻辑；`test/e2e/engine-parity.test.ts` 验证双引擎一致性。
