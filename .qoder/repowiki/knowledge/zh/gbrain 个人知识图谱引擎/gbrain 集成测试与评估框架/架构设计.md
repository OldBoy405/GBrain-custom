- **分层结构**：`test/e2e/` 负责基于真实数据库（Postgres/PGLite）的集成测试；`test/core/` 通过 Mock 模块隔离依赖，对重试、预算等核心逻辑进行单元测试；`evals/` 存放独立的 LLM 评估基准。
- **双引擎对齐**：采用 `engine-parity.test.ts` 模式，在相同数据集上对比 Postgres 与 PGLite 的行为一致性，确保迁移安全。
- **辅助设施**：`test/helpers.ts` 封装了数据库生命周期管理（`setupDB`/`teardownDB`）、数据导入及性能计时工具。
- **评估隔离**：`evals/functional-area-resolver` 使用 Node.js harness 调用 gbrain 网关进行 A/B 测试，并通过 `.gitignore` 确保评估数据不被打包进生产环境。
