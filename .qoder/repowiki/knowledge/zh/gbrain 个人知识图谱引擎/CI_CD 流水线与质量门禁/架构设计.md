- **入口编排**：`ci-local.sh` 作为核心入口，基于 Docker Compose 编排多实例 PostgreSQL 集群，协调 gitleaks 扫描、单元测试与 E2E 测试的执行流程。
- **测试调度层**：`sharding.ts` 实现基于 LPT（最长处理时间优先）算法的权重感知分片逻辑；`run-e2e.sh` 负责单文件串行执行以规避数据库状态竞争，并提供严格的 HOME 目录隔离机制。
- **智能选择器**：`select-e2e.ts` 通过 Git diff 分析变更范围，结合 `e2e-test-map.ts` 映射关系实现 E2E 测试用例的精准筛选与故障闭环保护。
- **静态检查矩阵**：包含数十个 `check-*.sh` 脚本，分别针对测试隔离性（如禁止 env 突变）、隐私合规（如敏感词过滤）、代码风格及架构约束进行静态扫描。
- **构建生成器**：`build-*.ts/sh` 脚本负责将 SQL Schema、Admin 前端产物等外部资源转换为 TypeScript 嵌入式常量，确保编译后二进制文件的自包含性。
