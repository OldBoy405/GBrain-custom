## 故意删除或禁用的内容

| 日期 | 路径/配置 | 原因 |
|------|-----------|------|
| 2026-07-04 | Windows PGLite 使用 `bun build --compile` 作全局 CLI | 编译产物无法释放 `pglite.data` WASM（`$$bunfs/root` ENOENT，上游 #1340）；改用 cmd shim |
| 2026-07-04 | Windows 使用 `bun link -g gbrain` | 易链到空 `global/node_modules/gbrain`，导致 Module not found |
